# База знаний: чрезмерное увлечение играми у детей

Тема: ребёнок школьного возраста, много играет (Roblox, Minecraft), родитель встревожен.
Кому: родителям, через агента `igrozavisimost-konsultant`.

## Статус базы

База собрана на **проверяемых источниках** — МКБ-11, DSM-5-TR, русскоязычная научная литература,
рекомендации ВОЗ и AAP. Полный перечень со статусами — в [`00-istochniki.md`](00-istochniki.md).

Четыре книги, изначально заявленные как основа базы (Иванов 2020, Смирнова 2019, Петрова 2021,
Сидоров 2018), **подтвердить не удалось** — см. [`istochniki/REESTR.md`](istochniki/REESTR.md).
Их содержание в базу не вошло. Если у вас есть эти книги в файлах — положите их в `istochniki/`
и попросите агента `igrozavisimost-bibliotekar` их законспектировать.
