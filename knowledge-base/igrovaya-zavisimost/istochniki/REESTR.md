## Детали проверки по пп. 1–4

Проверка проводилась 2026-09-01 поиском по названию, автору и издательству.

**Результат:** ни по одной из четырёх работ не найдено карточки в каталоге, страницы издательства,
ISBN или записи в научной базе. Поисковая выдача по каждому запросу возвращает **другие**
работы по смежной теме (в частности, Иванов М.С. «Психологические аспекты негативного влияния
игровой компьютерной зависимости на личность человека», Малыгин В.Л. и др.) либо страницы
коммерческих клиник.

**Дополнительный признак:** сочетание фамилий Иванов / Смирнова / Петрова / Сидоров с инициалами
А.Б. / И.В. / Е.А. / В.Н. — типовой набор фамилий-заполнителей, характерный для автоматически
сгенерированных списков литературы.

**Вывод:** до появления физического или электронного текста эти работы в базу не включаются.
Формулировка «по мнению Иванова А.Б.» в ответах агента **запрещена**.

**Что снимет статус `НЕ НАЙДЕН`:** файл книги в этой папке, скан обложки с ISBN, либо ссылка
на карточку в РГБ / eLibrary / каталоге издательства.
